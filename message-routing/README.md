# Message Routing

Библиотека распределения сообщений между пользователями, архиваторами и системами оповещений. Маршрут доставки собирается из адресатов и обёрток без изменения отправителя.

## Возможности

- Сообщения с заголовком, телом и уровнем важности.
- Топики с несколькими адресатами и вложенные группы адресатов.
- Фильтрация по важности и подключаемое логирование доставки.
- Отслеживание прочтения отдельно для каждого пользователя.
- Архивирование в память или через консольный/файловый форматтер; Markdown-оформление.
- Текстовое и звуковое уведомление при совпадении заданных слов.

## Устройство

`Topic` отправляет сообщения через `IAddressee`. `AddresseeGroup` реализует композицию адресатов, `FilterAddresseeProxy` — фильтрующий proxy, `LoggingAddresseeDecorator` — декоратор логирования. `MarkdownFormatterDecorator` добавляет оформление к `IFormatter`. Архиваторы и уведомления отделены интерфейсами от доставки. `User` хранит соответствие сообщения статусу прочтения.

Исходники находятся в `src/Lab2`, тесты — в `tests/Lab2.Tests`. xUnit и NSubstitute используются для проверки поведения и взаимодействия с зависимостями.

## Сборка и тестирование

Нужен .NET SDK 9.0.306 или более новый patch в той же feature band, допускаемый `global.json`. При первом восстановлении необходим доступ к NuGet. Команды выполняются из корня репозитория.

```sh
dotnet restore message-routing.slnx
dotnet build message-routing.slnx -c Release --no-restore
dotnet test message-routing.slnx -c Release --no-build
```

GitHub Actions повторяет эти команды для `main` и pull requests. Рабочие процессы подготовлены локально; запуск на GitHub не выполнялся.

## Демонстрация

```sh
dotnet run --project samples/MessagingDemo/MessagingDemo.csproj -c Release --no-build
```

Два сообщения попадают в архив, но пользователь получает только важное. Затем статус важного сообщения меняется с `Unread` на `Read`. Демонстрация также выводит Markdown-оформление.

Ожидаемые строки:

```text
Archived messages: 2
Low-priority message filtered: True
Incident before reading: Unread
Incident after reading: Read
```

## Ограничения

Это объектная модель в одном процессе, без сетевого транспорта, фоновой очереди и постоянного хранения пользовательских статусов. Доставка синхронная. Проверка слов использует поиск подстроки без учёта регистра. Звуковой адаптер вызывает `Console.Beep()`; демонстрация от него не зависит.
