# Train Simulator

Библиотека моделирования маршрутов поездов на магнитной подушке. Вычисляет результат прохождения маршрута и затраченное время с учётом приложенных сил и ограничений скорости.

## Возможности

- Обычные и силовые участки пути, включая торможение отрицательной силой.
- Станции с ограничением скорости и временем посадки и высадки.
- Ограничение силы для поезда и скорости на завершении маршрута.
- Пошаговый расчёт скорости и расстояния с заданным временным шагом.
- Успешный результат со временем либо объект ошибки при неудаче.

## Устройство

`Train` хранит состояние движения. `Route` обходит композицию участков `ITrackSection`; `MagneticForceTrack`, `MagneticNormalTrack` и `Station` задают различное поведение через общий интерфейс. `Mass`, `Speed`, `Force`, `Length` и `Time` представляют параметры предметной области. `RouteResult` и `SectionResult` описывают ожидаемые исходы без исключений в основном сценарии прохождения.

Исходники находятся в `src/Lab1`, тесты — в `tests/Lab1.Tests`. Названия исходных типов и пространств имён сохранены.

## Сборка и тестирование

Нужен .NET SDK 9.0.306 или более новый patch в той же feature band, допускаемый `global.json`. При первом восстановлении необходим доступ к NuGet. Команды выполняются из корня репозитория.

```sh
dotnet restore train-simulator.slnx
dotnet build train-simulator.slnx -c Release --no-restore
dotnet test train-simulator.slnx -c Release --no-build
```

GitHub Actions повторяет эти команды для `main` и pull requests. Рабочие процессы подготовлены локально; запуск на GitHub не выполнялся.

## Демонстрация

```sh
dotnet run --project samples/TrainDemo/TrainDemo.csproj -c Release --no-build
```

Поезд проходит силовой участок, обычный путь, станцию и ещё один обычный участок. Вывод содержит `Route completed in 285.0 seconds.`.

## Ограничения

Это дискретная модель материальной точки, без сопротивления воздуха и инфраструктуры управления реальным поездом. Время зависит от шага расчёта. Для демонстрации используйте конечные параметры, положительную массу и положительный временной шаг: исходные value objects допускают ноль и не запрещают все нечисловые значения.
