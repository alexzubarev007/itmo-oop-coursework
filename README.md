# ITMO Object-Oriented Programming Coursework

Учебные проекты, выполненные в рамках курса «Объектно-ориентированное программирование» образовательной программы «Разработка ПО / Software Engineering» в ИТМО.

Репозиторий объединяет четыре самостоятельные работы. Каждая находится в отдельном каталоге, собирается и тестируется независимо. Основной прикладной проект курса — `banking-system` — вынесен в отдельный репозиторий.

## Проекты

| Проект | Задача | Использованные подходы |
|---|---|---|
| [Train Simulator](train-simulator/README.md) | Смоделировать прохождение поездом маршрута из магнитных путей и станций с ограничениями скорости и силы. | Композиция, полиморфизм, value objects, моделирование ожидаемых ошибок через типы результатов. |
| [Message Routing](message-routing/README.md) | Реализовать корпоративную систему доставки сообщений пользователям, архиваторам и системам оповещений. | Decorator, Proxy, Composite, Dependency Inversion, моки зависимостей в тестах. |
| [Battle Simulator](battle-simulator/README.md) | Реализовать ядро пошаговых боёв фэнтези-существ с модификаторами и заклинаниями. | Builder, Factory Method, Decorator, абстракция генератора случайных чисел, копирование состояния. |
| [File Manager](file-manager/README.md) | Создать консольное приложение для навигации и работы с локальной файловой системой. | Command, Chain of Responsibility, Builder, Visitor, разделение представления, парсинга и доменной логики. |

## Структура

Каждый каталог проекта содержит исходный код, тесты и самостоятельный README с описанием реализации, запуском и ограничениями.

```text
train-simulator/    # модель маршрутов поездов
message-routing/    # модель распределения сообщений
battle-simulator/  # ядро боя существ
file-manager/       # консольный файловый менеджер
```

## Сборка и тестирование

Нужен .NET SDK 9.0.306 или совместимый patch-релиз. Проекты собираются по отдельности, например:

```sh
dotnet restore message-routing/message-routing.slnx
dotnet build message-routing/message-routing.slnx -c Release --no-restore
dotnet test message-routing/message-routing.slnx -c Release --no-build
```

Корневой workflow GitHub Actions запускает эти проверки для всех четырёх проектов.

## Что демонстрируют работы

Работы сфокусированы на объектном проектировании: формировании границ предметной области, замене конкретных зависимостей интерфейсами, расширении поведения без изменения существующей логики и проверке сценариев unit-тестами. Они не позиционируются как production-сервисы: ограничения конкретных реализаций описаны в README соответствующих проектов.
