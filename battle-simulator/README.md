# Battle Simulator

Логическое ядро пошаговых боёв фэнтези-существ: конфигурация бойцов, наложение модификаторов, применение заклинаний и определение исхода сражения двух столов.

## Учебная задача

Реализовать объектную модель боя двух игроков, где существа атакуют по очереди, меняют характеристики и получают модификаторы. Состояние боя не должно изменять исходные существа на столах или в каталоге конфигураций.

## Возможности

- Пять типов существ: боевой аналитик, злобный боец, сундук-мимик, бессмертный ужас и мастер амулетов.
- Магический щит и мастерство атаки; модификаторы можно комбинировать.
- Заклинания увеличения атаки/здоровья, добавления щита и обмена характеристик.
- Столы вместимостью до семи существ.
- Чередование сторон в бою и случайный выбор цели.
- Копирование столов при создании боя: изменения во время сражения не переносятся обратно на исходные столы.

## Устройство

Фабрики `ICreatureBuilderFactory` создают настроенные builders, `CreatureBuilderBase` объединяет настройку характеристик и применение модификаторов. `MagicShield` и `AttackingSkill` оборачивают `ICreature`, а `IModifierApplier` отделяет применение обёртки от конкретного существа. Заклинания реализуют `ISpell`. `Table` отвечает за состав стола и выбор существ, `Fight` — за цикл боя. Источник случайности вынесен в `IRandom`.

Исходники находятся в `src/Lab3`, тесты — в `tests/Lab3.Tests`.

## Подходы проектирования

- Factory Method: фабрики создают builders разных существ через общий контракт `ICreatureBuilderFactory`.
- Builder: builders задают характеристики и набор модификаторов до создания существа.
- Decorator: `MagicShield` и `AttackingSkill` расширяют поведение `ICreature` без изменения конкретных существ.
- Dependency Inversion: `Table` получает генератор случайных чисел через `IRandom`, поэтому сценарии можно тестировать детерминированно.

## Сборка и тестирование

Нужен .NET SDK 9.0.306 или более новый patch в той же feature band, допускаемый `global.json`. При первом восстановлении необходим доступ к NuGet. Команды выполняются из корня репозитория.

```sh
dotnet restore battle-simulator.slnx
dotnet build battle-simulator.slnx -c Release --no-restore
dotnet test battle-simulator.slnx -c Release --no-build
```

GitHub Actions повторяет эти команды для `main` и pull requests. Рабочие процессы подготовлены локально; запуск на GitHub не выполнялся.

## Демонстрация

```sh
dotnet run --project samples/BattleDemo/BattleDemo.csproj -c Release --no-build
```

Аналитик с мастерством атаки сражается с мимиком под магическим щитом. По одному существу на стороне делают выбор цели однозначным. Исходные характеристики столов остаются прежними.

Ожидаемый вывод:

```text
First player won: True
Analyst on the table: 2/4
Mimic on the table: 1/1
```

## Ограничения

Это библиотека без графического интерфейса и сетевой игры. Для нескольких существ выбор целей случаен. В исходном `Table.FindAttacking` проверяется здоровье, но не положительная атака; бой с живыми существами без возможности наносить урон может не завершиться. Такие составы не включены в демонстрацию. Исходная реализация сохранена.
